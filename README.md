# bbw_visual_routine

A new Flutter project.

## BBW Visual Planner MVP

TEACCH-oriented daily/weekly planner with separate participant and staff
interfaces. Run it with:

```bash
flutter run -d chrome -t lib/main_mvp.dart
```

Demo accounts: `staff`, `admin`, `lena`, `jonas`, `mia`, `elias` (password `demo`).
See [docs/MVP_ARCHITECTURE.md](docs/MVP_ARCHITECTURE.md) for the architecture, the
schedule/change lifecycle, what is mocked, and how to extend it.
